# Coffiya

Coffiya is a warm, specialty coffee recipe website for casual coffee drinkers. It shares approachable brewing recipes, practical coffee tips, and a simple newsletter signup in a responsive single-page experience.

## Highlights

- Six featured specialty coffee recipes
- Espresso, cold brew, latte, pour-over, cortado, and Turkish coffee ideas
- Three practical brewing tips
- Responsive mobile navigation
- Newsletter email validation
- Semantic, accessible HTML structure
- Lightweight static site with no build step

## Preview

Open [`coffee/index.html`](coffee/index.html) directly in a browser, or serve the project locally:

```bash
python -m http.server 8000 --directory coffee
```

Then visit `http://localhost:8000`.
