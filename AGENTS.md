# AGENTS.md - Guiding Principles for Coffiya Project

## Project Overview
**Coffiya** - A specialty coffee recipe brand webpage designed to showcase a unique coffee recipe, build brand awareness, and encourage repeat visits from casual coffee drinkers.

## Development Approach
**Spec-Driven Development** - Each feature/product starts with a specification before any code is written.

### Project Structure
```
specs/
├── coffee/spec.md
├── pastary/spec.md
└── cookies/spec.md
```

### Workflow
1. Write spec first (requirements, design, content)
2. Review and finalize spec
3. Implement based on spec
4. Test against spec criteria

## Core Principles

### 1. User Experience First
- Keep the design **warm, cozy, and inviting** - reflect the comfort of a good coffee
- Prioritize simplicity - casual drinkers should understand the value instantly
- Mobile-first responsive design (most casual users browse on phones)
- Fast loading times - no heavy animations that slow down the experience

### 2. Content Strategy
- **Recipe is free** - build trust by sharing the full recipe openly
- Focus on storytelling - share the origin and passion behind the specialty blend
- Use high-quality visuals - warm tones, coffee imagery, inviting aesthetics
- Create "sticky" content that makes visitors want to return for more

### 3. Brand Building Goals
- Establish **Coffiya** as a premium yet approachable coffee brand
- Encourage social sharing to expand reach organically
- Build an email list for ongoing engagement
- Create a memorable brand identity that stands out

### 4. Technical Guidelines
- **Tech Stack**: Single static HTML file (HTML/CSS/JS)
- Keep it simple - no build tools or frameworks required
- Ensure fast loading by inlining CSS/JS and optimizing images
- Implement basic SEO with meta tags and semantic HTML
- Ensure accessibility standards (WCAG compliance)

### 5. Visual Design System
- **Color Palette**: Warm earth tones (browns, creams, amber, soft oranges)
- **Typography**: Clean, readable fonts with personality
- **Imagery**: Authentic coffee photography, lifestyle shots, recipe process
- **Layout**: Generous whitespace, easy-to-scan content blocks

### 6. User Journey
- **Entry**: Clear value proposition - "Discover the perfect specialty coffee"
- **Engagement**: Recipe showcase with step-by-step visuals
- **Conversion**: Newsletter signup, social follow, or recipe download
- **Retention**: Regular content updates, seasonal recipes, coffee tips

### 7. Quality Standards
- Code must be clean, well-organized, and documented
- Use semantic HTML and modern CSS practices
- Implement proper error handling and fallbacks
- Test across browsers and devices

## Success Metrics
- Return visitor rate (primary goal)
- Time spent on page
- Social shares and mentions
- Email subscriber growth
- Brand recognition in coffee community

## What We Are NOT
- Not an e-commerce store (recipe is free)
- Not a complex web app (keep it simple and focused)
- Not targeting coffee experts (casual drinkers are our audience)
- Not using dark/heavy design (warm and cozy is our aesthetic)
